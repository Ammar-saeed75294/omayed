Omayed Protected Area — Vegetation Cover

Analysis CRS: UTM 35N (EPSG:32635) · NDVI · 1990–2020

A multi-temporal NDVI analysis of vegetation cover trends within the Omayed Biosphere Reserve, Matrouh Governorate, Egypt.

Prepared by Ammar Saeed · AAST / GIS · 05/09/2026

This report tracks vegetation greenness across the Omayed Protected Area using the Normalized Difference Vegetation Index (NDVI), derived from four raster snapshots spanning 1990, 2000, 2010 and 2020. Each raster is classified into five cover classes, from open water / non-vegetated ground through a single merged "green land" class (NDVI 0.2–1.0), so vegetated area can be read directly from the map.

Note on scope: the source material provided was raw NDVI imagery, not an administrative boundary or land-designation ("dedication") dataset. This report is framed as a vegetation-cover change assessment, which is what the underlying data supports.

Data notes & caveats

Read before citing these figures

  • The live satellite/street basemap only loads when this file is opened normally — double-clicked from your downloads folder, opened in a regular browser tab, or hosted on a site like GitHub Pages. If you are viewing this inside Claude's own in-chat preview, the map tiles will appear blank: Claude's preview sandbox blocks requests to outside image servers (including Esri's and OpenStreetMap's) for security reasons. This is a platform limitation, not a bug in the file — download it and open it directly to see the imagery.
  • Two coordinate systems are used deliberately, not by mistake. The interactive map renders in Web Mercator (EPSG:3857), the projection every standard web map (Esri, Google Maps, OpenStreetMap) uses for tile display. The quantitative analysis — the statistics table, the scale bar reasoning, and area percentages — was computed on the data reprojected to UTM Zone 35N (EPSG:32635), an equal-distance projection appropriate for measuring area and distance in this region. State both if asked about methodology.
  • Classification was changed to five classes on request: NDVI 0.2–1.0 is now one merged "Green land" class, rather than being split into moderate/dense vegetation as in an earlier draft. This is a coarser view of the same data — useful for a simple vegetated/non-vegetated read, less useful for distinguishing sparse shrubland from denser stands.
  • 2020 is still not directly comparable to the other three years. Its mean NDVI (0.179) is roughly three times 1990–2010 levels, and it uses a different no-data convention. That is more consistent with a different source scene or processing pass than a real three-fold greening in one decade — say so if you present the 1990→2020 trend as continuous.
  • All statistics exclude masked / no-data pixels; valid coverage varies by year (85–92% of the extent), which affects the comparability of area-based percentages.
