Omayed Protected Area — Vegetation Cover

EPSG:32635 · NDVI · 1990–2020

A multi-temporal NDVI analysis of vegetation cover trends within the Omayed Biosphere Reserve, Matrouh Governorate, Egypt.

Prepared by Ammar Saeed · AAST / GIS · 05/09/2026

This report tracks vegetation greenness across the Omayed Protected Area using the Normalized Difference Vegetation Index (NDVI), derived from four raster snapshots spanning 1990, 2000, 2010 and 2020. Each raster is classified into six cover classes, from open water / non-vegetated ground through to dense vegetation, so change over the 30-year period can be read directly from the map rather than inferred from raw index values.

Note on scope: the source material provided for this project was raw NDVI imagery, not an administrative boundary or land-designation ("dedication") dataset for the reserve. This report is therefore framed as a vegetation-cover change assessment, which is what the underlying data supports — not a record of formal re-zoning or protected-area status changes. If your project brief specifically requires the latter, that would need a separate boundary/zoning shapefile.

Data notes & caveats

Read before citing these figures

  • 2020 layer is not directly comparable to the other three. The 1990/2000/2010 rasters share one no-data convention and a similar valid-pixel share (~91–92% of the extent); the 2020 file uses a different no-data value and covers only ~85% of the extent, and its mean NDVI (0.179) is roughly three times the earlier years. That pattern is more consistent with a different source scene, compositing method, or cloud-masking pass than with a genuine three-fold greening of the reserve in one decade. Treat the 1990→2010 trend and the 2020 value as two separate claims, not one continuous series, unless you can confirm the 2020 raster was processed the same way as the others.
  • All statistics exclude masked / no-data pixels; coverage varies slightly by year (85–92% of the raster extent), which itself affects comparability of area-based percentages.
  • Class breaks (0, 0.05, 0.10, 0.20, 0.40) are a fixed classification chosen for this arid coastal ecosystem, not a standardized global NDVI scheme — state this if your instructor asks about methodology.
  • The sidebar key map is a schematic locator only (coastline and city positions are approximate) — it is separate from the main map's base layer. Live satellite/street tiles (e.g. OpenStreetMap, Esri) cannot be fetched by this offline export, so the main map's base layer is instead derived directly from the 1990 raster's own water/non-vegetated mask, reprojected to UTM 35N. It is real data from your imagery, not an independent basemap source — say so if your instructor asks what basemap was used.
  • All four years now share one coordinate grid (UTM Zone 35N / EPSG:32635, ~27.4 m pixels), reprojected by bilinear resampling from the original WGS 84 rasters. Reprojection changes pixel values by a fraction of a percent at most — negligible next to the 2020 discrepancy noted above.
  • Sensor / imagery source was not included in the uploaded files; if your original project cites a specific satellite (e.g. Landsat), add that citation manually — it is not asserted here.
